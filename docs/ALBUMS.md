# Album grouping and moving songs

Albums use the current catalog album title and album artist, falling back to the song's artist if the album artist is blank. Matching ignores case and surrounding whitespace. Songs in different folders with the same album and artist appear together; the same title by different artists remains separate. Existing catalog entries regroup immediately, without rescanning.

Scanning also recognizes album folders containing a `.nfo` file, or a local cover (`cover.jpg`, `cover.png`, `folder.jpg`, `folder.png`, or `front.jpg`) and at least two audio files. For example, `C:\Users\Danny\Desktop\slskd\music\The Weeknd\Starboy (2016)` is an album folder. XML album NFO files supply missing title, album artist, year, and genre; `album.nfo` takes priority over other NFO filenames. Plain-text or malformed NFO files still identify a release folder, using its name for the title and its parent folder for the artist. A trailing `(2016)` supplies the year and is removed from the inferred album title. A single XML artist can supply the album artist when that field is absent.

Embedded tags remain authoritative. Missing song artists use the folder's album artist, so guest credits do not split an untagged release. Numbered filenames such as `1-02 - Party Monster.flac` supply missing disc/track numbers and a clean song title. Existing local cover handling supplies artwork; `proof.jpg` is not used as a cover. Loose files without release sidecars remain singles when they have no album tags. Detection applies only to files directly in the release folder. Run a **full scan** to apply this detection to already indexed files or after editing/adding sidecars; incremental scans skip unchanged audio files. Catalog metadata overrides and manual album moves survive rescanning.

As an administrator, open a song's actions menu, choose **Edit metadata / artwork…**, then **Move to album…**. Search for the destination, select it, and choose **Move song**. Save or discard unsaved metadata edits before moving.

Moving immediately applies both the destination's album title and album artist. Other song metadata and the music file stay intact. The assignment survives rescans. To undo a move, move the song back or restore its extracted album and album artist in the editor. Empty albums disappear from the album list automatically. Songs classified as singles can also move into an album.

Album lists and destinations respect library exclusions. Existing exclusions using extracted album IDs remain supported; newly selected album exclusions apply to the complete metadata group.
