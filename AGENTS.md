# Repository workflow

- Commit each completed logical change, including documentation and configuration changes, as requested by the owner.
- Run checks appropriate to the change before committing, and describe any verification limitations.
- Use meaningful commit messages and keep the working tree clean after completing work.
- Never commit secrets, local environment files, generated caches, test databases, or downloaded tools. Keep `.env.example` tracked with placeholder values.
- Do not push commits or publish releases unless requested.
